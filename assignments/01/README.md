# Agent Skills 学习资料

本目录是一份完整的 **《Agent Skills 学习资料》**，以交互式网页形式呈现。

## 文件说明

| 文件 | 说明 |
|---|---|
| `agent-skill-learning.html` | 学习资料成品页面（双击用浏览器打开即可查看） |
| `janus.data.json` | 页面源数据（WorkBuddy 在线 Page 引擎使用，如需继续在 WorkBuddy 中编辑此页面需保留） |

## 内容大纲

1. 什么是 Agent Skill
2. 核心原则：渐进式披露（Progressive Disclosure）
3. SKILL.md 的结构（frontmatter + 正文）
4. 技能目录结构
5. 为什么捆绑代码
6. 编写最佳实践
7. 安全注意事项
8. 测试题（分级）
9. 参考来源

## 如何查看

- 直接在访达中双击 `agent-skill-learning.html`，会用默认浏览器打开；
- 或在 GitHub 仓库页面打开本目录后点击该 HTML 文件查看源码。
